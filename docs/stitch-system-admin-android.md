# FacilityCore — system admin website

Create 3 separate website pages, S1 through S3. Each section below is a new page. Do not edit, replace, restyle, or overwrite a page you already made. Keep all 3.

This is the FacilityCore staff website. FacilityCore staff only. A resident never sees it. A society secretary, treasurer, or facility manager never sees it. Sign-in is the same mobile code. This role lands on the dashboard.

## Master

These pages are a desktop website dashboard, 1440px wide. Do not draw a phone, a phone frame, or an Android screenshot.

Look: warm off-white #F7F6F3, ink text #1C1B19, secondary text #6F6A63, 1px lines #E4E0D8. One plain sans-serif. No shadow, gradient, illustration, emoji, icon grid, or 3D. One filled button, black #1C1B19, label #F7F6F3, 48px tall, sized to its label. Any other action is plain text. Red #9C3B2E only for a suspended society. Green #1F6B45 is not used on these pages.

Chrome on every page: a top bar, full width, hairline under it. Left: “FacilityCore”. Right: text link “Log out”. Page content sits below, left aligned, 48px from the edges. No left sidebar. No society menu.

English labels. Do not add bills, payments, complaints, vendors, a services shop, visitors, charts, or resident names on the society list.

S1, S2, and S3 are three different pages. Add each one. Leave the others as they are.
